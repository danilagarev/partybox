# Вечеро

Временное название приложения; окончательный нейминг ещё не выбран.
Техническое имя проекта и пакетов — `partybox`.

Игры для компании от четырёх человек на Android и iOS. Два режима: один телефон
передаётся по кругу и каждый играет со своего телефона. Стиль — премиальный;
целевой результат — публикация в магазинах.

Реализована полная локальная партия «Шпион»: подготовка, личные роли, обсуждение
с таймером, общий выбор подозреваемого, результат и повтор. Flutter-приложение
работает без сервера; правила вынесены в чистое Dart-ядро, контент включён в assets.
Имена и настройки сохраняются локально; активная партия после закрытия не восстанавливается.
Три встроенные темы «Шпиона» содержат 72 локации; доступны выбор темы, подсказки
для обсуждения и ротация без повторов до конца набора. Выбор темы сохраняется;
локальная история действует до выхода из игры, сетевая — на время жизни комнаты.
Сетевая партия «Шпион» реализована в сборке с ROOM_SERVER_URL: комната по PIN,
личные роли, подтверждения, обсуждение, выбор ведущего, результат и повтор.
Сервер авторитетен, состояние и повторы команд сохраняются в PostgreSQL.
Локальная игра остаётся независимой от backend. Телефонная проверка локального
режима принята. Комплект HTTPS/VPS проверен локально; публичный сервер ещё
не развёрнут, четыре физических сетевых устройства и iOS не проверены. Восстановление локального раунда
и покупки ещё не реализованы.

## Быстрый старт

Нужны Node из `.nvmrc`, npm 11 и Flutter из `.fvmrc` (с комплектным Dart).

```sh
make bootstrap
make check
make mobile
```

Для работы только с сервером и контентом Flutter не нужен:

```sh
npm ci
npm run check
npm run dev:backend
```

Проверка сервера: `curl http://127.0.0.1:3000/health` → `{"status":"ok"}`.
Инструкции по платформенным SDK, FVM и портам: [разработка](docs/DEVELOPMENT.md).
Сервер для телефонов: [VPS/HTTPS](docs/deploy/VPS.md); локальная проверка —
`node deploy/smoke.mjs` при работающем Docker.

## Карта проекта

| Путь                      | Назначение                                      |
| ------------------------- | ----------------------------------------------- |
| `apps/mobile`             | Flutter-клиент Android/iOS                      |
| `packages/game_core`      | Правила локальной игры, чистый Dart             |
| `apps/backend`            | NestJS; сервер комнат, затем правила            |
| `packages/game-contracts` | Версионированные JSON-схемы                     |
| `packages/game-content`   | Авторский контент и его валидация               |
| `docs`                    | Требования, архитектура, правила, backlog и ADR |

Начало работы агента: [AGENTS.md](AGENTS.md). Следующая задача:
[backlog](docs/BACKLOG.md). Фактическое состояние: [STATUS](docs/STATUS.md).
Причины выбора стека: [архитектура](docs/ARCHITECTURE.md).

нужно после подключения remote включить обязательные проверки `node`, `flutter` и `https`
в настройках хостинга. Репозиторий: [danilagarev/vechero](https://github.com/danilagarev/vechero).
Защита ветки, публикация приложения и production-секреты ещё не настроены.
