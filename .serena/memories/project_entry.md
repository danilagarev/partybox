# Вход в PartyBox

Проверено 2026-11-23. Это маршрутизатор, а не копия документации.
После изменения кода перепроверь утверждения по исходникам и тестам.

- Правила: `AGENTS.md`. Процесс: `docs/WORKFLOW.md`.
- Выбери модуль: `node scripts/project-context.mjs <модуль>`.
- Требования: нужный раздел `docs/PRODUCT.md`; состояние: нужный раздел `docs/STATUS.md`.
- Текущая задача и передача: `docs/plans/PB-XXX-*.md`, сначала раздел «Передача работы».
- Решения: `docs/adr/`; правила игр: `docs/GAME_RULES.md`; сеть: `docs/PROTOCOL.md`.
- Проверки с коротким выводом: `node scripts/run-check.mjs node|mobile|release|context`.
  Логи/JSON в игнорируемом `output/checks/`; квитанция содержит fingerprint исходников.
  Квитанция не гарантирует неизменность SDK, зависимостей, окружения и БД.
- Производительность: `docs/PERFORMANCE.md`; процесс и инструменты памяти:
  `docs/AI_DEVELOPMENT.md`; прод: `docs/deploy/PRODUCTION.md`.

Ищи символ → ссылки → нужное тело. Для небольшого текста/конфига достаточно `rg`.
Generated-контракты не редактировать: схема → примеры → генератор → обе стороны.
В конце задачи обнови план: результат, решения, пути, проверки, оставшийся шаг.
Память не подтверждает прохождение проверок и не отменяет указания пользователя.
