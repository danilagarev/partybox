# PB-047 — русский контент первого выпуска

## Объём и версии

| Игра / тема                          | ID набора           | Версия | Карточек |
| ------------------------------------ | ------------------- | ------ | -------- |
| Шпион / Знакомые места               | `spy-ru-base`       | 3      | 60       |
| Шпион / Вокруг света                 | `spy-ru-travel`     | 2      | 60       |
| Шпион / За гранью обычного           | `spy-ru-unusual`    | 2      | 60       |
| Шкала терпения / Мелкие неприятности | `tolerance-ru-base` | 2      | 220      |

Всего 180 локаций и 220 ситуаций. Источник — JSON в

Контент встроен в приложение и сервер, загрузка внешних наборов не требуется.

## Редакционные границы

Карточки написаны для проекта; цитаты, персонажи и названия чужих игровых наборов
не использованы. Это описание происхождения текста, а не юридическое заключение
или подтверждение рейтинга магазина.

«Знакомые места» — повседневные городские локации с понятными занятиями и
предметами. «Вокруг света» — поездки, природные места, достопримечательности и
туристическая инфраструктура. «За гранью обычного» — фантастические и необычные
места, включая исследовательские объекты. Перед этой темой участникам полезно
договориться, как они представляют вымышленные места. Космическая станция
перенесена из повседневной темы в необычную, туристический лагерь убран из
повседневной темы, чтобы не дублировать кемпинг в путешествиях.

У каждой локации краткое самостоятельное название; нет обязательных знаний
конкретной страны, франшизы или произведения. Разные объекты одной сферы
различаются действиями: например, радиостудия и фотостудия. Вопросы во время
игры формулирует сама компания.

«Мелкие неприятности» рассчитаны на компанию взрослых, без эксплицитных тем.
Набор включает технику, еду, дом, одежду, дорогу, покупки, общение и увлечения.
40 карточек посвящены работе, свиданиям, общим деньгам, вечеринкам и привычкам
партнёров — по восемь на каждую тему. Отдельного набора 18+ нет.
Одна карточка описывает одну бытовую или социальную ситуацию, которую
можно сравнить с тремя другими по личной реакции. Нет заданного «правильного»
порядка, цены ущерба или оценки характера игрока. Ситуации не требуют признаний
или выполнения действий. Нет сексуального контента, травм, насилия,
дискриминационных характеристик или опасных испытаний. Это редакционная граница
набора; итоговую анкету возрастного рейтинга заполняют для всего приложения.
Игровой состав — 4–12 друзей по текущим правилам; карточки не задают возраст
доступа в магазине.

## Совместимость и развёртывание

Структура JSON и `schemaVersion: 1` сохранены. Схема исходного набора терпения
совместимо расширена: до 240 карточек и ID `tolerance-` с двумя или тремя цифрами.
Существующие ID 01–60 сохранены; новые продолжают последовательность до 220.
Это ID исходного контента, не новые значения сетевого протокола.

Публичный протокол v3 сохраняет двухзначные ID. Серверный адаптер должен после
выбора карточек на партию присвоить им локальные ID `tolerance-01`…`tolerance-48`
(по четыре на каждого из 12 героев). Так новые тексты доступны прежнему клиенту
без изменения regex в его DTO. Без такого адаптера выдача исходных ID 100–220
несовместима с прежним клиентом: обновлять только JSON на сервере нельзя.

Для «Шпиона» ключ истории — `packId:version`; новые версии начинают независимый
проход без повторов. Активный раунд сохраняет ранее выбранную локацию и версию.
Для терпения активная партия хранит уже выбранные карточки. Подмена контента
не должна менять её карточки или результаты. При выпуске серверный адаптер,
наборы, каталог и схема собираются вместе. Обновление мобильных assets требует
новой сборки приложения; изменения JSON в репозитории не обновляют установленный
APK или работающий backend. Деплой и проверка сохранённых комнат после рестарта
в эту редакционную задачу не входят.

## Проверки

`npm test --workspace=@partybox/game-content` проверяет схемы, точные объёмы,
согласованность каталога и версий, уникальность ID и текстов, отсутствие пустых
карточек, границы 48/240 исходных карточек и допустимую длину ID. Точные
совпадения локаций проверяются между всеми тремя темами. Различимость близких
ситуаций и отсутствие запрещённых тем дополнительно проверены редакционно;
автоматическая проверка уникальных строк не заменяет такую вычитку.

Текущий объём — редакционная готовность встроенных наборов. Он не означает
пройденное ревью App Store / Google Play или завершённый деплой сервера.
