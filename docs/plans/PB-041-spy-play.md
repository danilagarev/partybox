# План: PB-041 — «Шпион» с друзьями по Wi-Fi и через интернет

## Результат

Ведущий запускает игру одной командой на компьютере, друзья открывают адрес
в браузерах своих телефонов, входят по коду, смотрят роли, обсуждают, голосуют
вслух и играют повторно. Перезагрузка той же вкладки сохраняет участие.

Пользователь 2026-11-21 выбрал отдельные телефоны в одной Wi-Fi сети, затем
добавил возможность играть через интернет. Публичный production-сервер не выбран;
покупки, DNS и магазинная публикация в поручение не входят.

## Границы и зависимости

Правила «Шпиона» и протоколы не меняются. Существующая серверная механика уже
проходит автоматические полные циклы. Этот срез закрывает практический запуск
на телефонах, восстановление браузерного доступа и неудобства готовности.
Прежние изменения PB-031 и переименования сохраняются.

Wi-Fi: profile web с HTTP в доверенной локальной сети, один origin для файлов,
HTTP API и WebSocket. Backend и временная PostgreSQL доступны только локально.
Интернет: release web, явный запуск временного HTTPS-туннеля cloudflared;
для постоянного адреса остаётся существующий VPS-комплект. Туннель создаётся
только командой интернет-запуска. Ограничения — [ADR 0008](../adr/0008-browser-play.md).

## Проверка

`npm run check` с PostgreSQL; `make check-mobile`; opt-in четыре Dart-клиента
с одновременными spy.ready; Node-тесты proxy/static/WS; фактический запуск LAN
и браузерные проверки. Интернет-сборку проверить отдельно через локальный HTTPS.
Публичный туннель и физические телефоны не объявлять проверенными без прогона.

## Передача работы

Основной агент — подтверждение ролей, UI, интеграция и руководство.
Агент mobile — same-origin и браузерный RoomVault с тестами.
Агент tooling — launcher/proxy и проверки маршрутизации/приватности файлов.
Независимое чтение существующего «Шпиона» блокирующих ошибок не выявило;
замечания по новым изменениям будут проверены отдельно.

## Результаты приёмки

Проверены полный LAN-цикл, refresh той же вкладки, локальный HTTPS release и wss,
4 tools теста, 20 backend/10 contracts/3 content, 8 core/93 app. Отдельно прошёл
полный real-client цикл через proxy и остановка изолированного стенда.
[Браузерный отчёт](../design/pb-041/verification.md).

APK 0.1.0+2 собран в корне как `partybox-test.apk`, debug для Wi-Fi сервера
192.168.1.241:8720; подпись и архив проверены. Проверка физического телефона
остаётся пользователю.

Внешний туннель не подтверждён: первый запуск не выдал адрес, последующая
диагностика публичного подключения к действующему LAN-стенду отклонена auto-review.
Следующий внешний шаг требует явного разрешения на отдельный публичный тестовый
стенд. Постоянного домена/публикации нет; локальный HTTPS не заменяет внешний тест.
