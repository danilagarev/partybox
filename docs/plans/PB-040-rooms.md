# План: PB-040 — комнаты и онлайн для «Шпиона»

## Результат

Сначала проверяемый серверный срез комнаты: создание → вход четырёх участников
по PIN → snapshot по личному токену → reconnect → выход ведущего и передача
управления → восстановление после рестарта. Затем мобильное лобби и полная партия.
Пользователь выбрал онлайн следующим этапом 2026-11-08.

## Границы и зависимости

Подтверждено: комната живёт 24 часа с создания; явный выход ведущего передаёт
управление следующему участнику по порядку входа; обрыв связи сохраняет место.
Телефонная проверка локального приложения принята пользователем.
Первый срез меняет backend, контракты и среду разработки. Локальная игра работает
независимо. Сетевой игровой процесс и Flutter-клиент — последующие срезы PB-040.

- [x] Идемпотентность, ограничение попыток PIN, предел состава, reconnect/snapshot.

## Проверка

`npm run check`, интеграционные тесты с отдельной PostgreSQL БД.
Для сервера — четыре независимых HTTP/Socket.IO-клиента, повтор и конфликт команд,
гонка заполнения 12-го места, рестарт приложения, чужой токен, TTL и лимиты.
Flutter и физическая партия проверяются после реализации мобильного среза.

## Передача работы

Серверный срез лобби реализован. `npm run check` с TEST_DATABASE_URL прошёл
на настоящей PostgreSQL 16.15, включая четыре HTTP/Socket.IO-клиента, гонки,
рестарт backend и потерю соединения. CI использует PostgreSQL service.
Docker Compose подготовлен, но локально не запущен из-за доступа к Docker socket;
для тестов использован временный PostgreSQL в /tmp.

Мобильный срез добавляет создание/вход по PIN, список участников и ведущего,
восстановление по токену, reconnect и явный выход. Токен и незавершённые запросы
сохраняются через отдельный SecureRoomVault; [ADR 0004](../adr/0004-mobile-room-access.md).
Dart валидирует данные по generated-схеме game-contracts, включая общие примеры.
Проверены четыре настоящих Dart HTTP/Socket.IO-клиента с PostgreSQL, потерянный
ответ, восстановление, передача ведущего, ошибки хранения и фон/возврат.

Сетевой цикл реализован по [ADR 0005](../adr/0005-network-spy.md): контракты v2,
авторитетные TS-правила, отдельные личные проекции, дедлайн, идемпотентность,
Flutter-карточки/подтверждения/обсуждение/выбор/результат/повтор. Общие JSON-векторы
проверяются в TS и чистом Dart. [Ревью лобби](../reviews/PB-040-lobby.md).
Остаётся физическая приёмка на четырёх телефонах, iOS и развёрнутый HTTPS backend;
PB-040 целиком ещё открыта.
