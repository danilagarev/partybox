# PB-048 — «Что объединяет?» и общий веб-клиент

## Результат

PartyBox содержит три игры. «Что объединяет?» работает одному без сервера и
в комнате на 1–12 участников. Браузер и Android используют общий Flutter UI.
Production-комплект отдаёт веб, HTTP и Socket.IO с одного HTTPS-домена.

Пользователь подтвердил Flutter для веба. Дополнительное требование: у «Шпиона»
основные действия видны без прокрутки на обычном размере текста; движение
карточки не прокручивает страницу. Крупный текст и длинные списки не обрезаются.

## Правила первого среза

Допущения реализации: пять заданий, четыре подсказки от общего к конкретному,
4/3/2/1 очко за верный ответ. Письменный ответ проверяется по авторским синонимам:
нижний регистр, ё→е, знаки заменяются пробелами, лишние пробелы удаляются.
ИИ и приблизительное совпадение не используются. За одно задание максимум 4 очка.
После неверной попытки новую можно сделать при следующей подсказке.

В комнате ведущий открывает общую следующую подсказку. Все верные ответы
завершают раунд; на четвёртой подсказке раунд завершается после ответов всех.
Ведущий может явно закончить последнюю подсказку, чтобы не ждать отошедшего игрока.
Ответы/синонимы/будущие подсказки не входят в публичную проекцию до раскрытия.
Повтор команды не начисляет очки дважды; устаревший clueIndex отклоняется.
Ведущий переводит результат в следующее задание; после пятого — общий итог.

## Границы и зависимости

- Content agent: отдельный clues pack, schema и тесты качества.
- Backend agent: чистые TS-правила, rooms-v4, совместимость 1/2/3, PostgreSQL,
  приватные проекции, опциональная раздача публичных web-assets.
- Solo agent: чистый Dart, offline solo, новые Flutter screens и каталог.
- Root: мобильный сетевой клиент v4, web-host/сборка/CD, интеграция и приёмка.
- После контента — отдельная полировка Spy layout в согласованных файлах.

Никакого универсального игрового движка. Новая версия контракта с примерами и
генерацией обязательна; старые APK не получают неизвестный формат.
Секретные письменные ответы не сохраняются в RoomVault/retry storage.
Web sessionStorage остаётся привязанным к вкладке; изменение модели хранения
и полноценный offline web cache не включаются без отдельного решения.

## Проверка

Чистые TS/Dart-векторы правил, границы, незаконные действия, normalization,
схемы/generated parity, PostgreSQL integration, старые протоколы, утечки
публичных данных и retry. Flutter: полный solo и network цикл, 320×640,
крупный текст/клавиатура, lifecycle/reconnect. Веб: реальный браузер, четыре
изолированных контекста, все три игры; production smoke за отдельным Caddy.
Отдельно asset delivery/no-store и отсутствие API/секретов в offline cache.
Android/iOS физическую проверку не подменять браузером.
