# План: PB-026 — заглянуть под карточку

## Результат

В локальном и сетевом «Шпионе» игрок тянет обложку вверх и удерживает, чтобы
прочитать роль. Отпускание закрывает её, передача/подтверждение — отдельное действие.
Открытие кнопкой сохраняется для клавиатуры, screen reader и чтения крупного текста.

## Границы и зависимости

Запрошено пользователем 2026-11-09 перед PB-030. Поведение «удерживать для просмотра,
отпустить для скрытия» — рабочее решение реализации. Никаких новых сетевых команд
или правил победы: меняется только способ просмотра и локальный признак прочтения.
До просмотра подтвердить передачу нельзя. Смена игрока/раунда сбрасывает этот признак.
Фон, отмена жеста, второй палец, выход и disconnect немедленно удаляют секрет,
в том числе из semantics. Возврат/переподключение не продолжает старый жест.
Декоративная обложка может двигаться; закрытая роль не хранится в outgoing-анимации.
Reduced motion сохраняет жест и отключает декоративный довод обложки.

один opt-in сетевой тест пропущен без ROOM_TEST_SERVER. Node check прошёл,

удержание мышью, отпускание с очисткой semantics и явная передача следующему;
ошибок консоли нет. Просмотрены и обновлены эталоны раздачи, ролей и диалога выхода.

## Передача работы

Домен sorima.tech указан пользователем для будущего backend на поддомене;
конкретное имя ещё не выбрано, DNS и VPS не меняются. После этого среза — PB-030.

Реализация готова. Известные ограничения: жест на физическом touch-устройстве,
TalkBack/VoiceOver и haptics ещё не проверены; Linux-среда без подключённых
телефонов и macOS/Xcode. Новый APK в этой итерации не собирался.
