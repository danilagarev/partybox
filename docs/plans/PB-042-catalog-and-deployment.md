# План: PB-042 — каталог игр и production CI/CD

## Результат

Пользователь сразу видит обе реализованные игры и понимает доступные режимы.
«Шпион» запускается на одном телефоне или в комнате, «Шкала терпения» — в комнате.
Вход по коду и возврат в существующую комнату доступны из главного меню.
Адрес комнат меняется в приложении после настройки своего поддомена.

Backend получает проверяемый CI/CD-комплект для отдельного Docker-проекта на
имеющемся сервере рядом с другим приложением, за существующим Nginx. Пользователь
настраивает домен, SSH, registry и GitHub Environment; действующий сервер в этой
итерации не изменяется.

## Границы и зависимости

Поручение пользователя от 2026-11-21. Подтверждён Nginx. GitHub Actions/GHCR
используются на основе существующего репозитория и CI; поддомен остаётся
настраиваемым. Дизайн сохраняет выбранный «Полночный клуб»: новые композиция,
графика карточек и маршруты используют действующие токены/Manrope/компоненты.

Причина проблемы: каталог содержит только карточку «Шпиона», а второй игре
соответствует переключатель внутри сетевого лобби. При отсутствии build URL
сам вход в комнаты скрыт. Новая навигация исправляет обе причины.
Игровые правила, секретные проекции и контракт v3 не меняются.

## Проверка

`npm run check` с PostgreSQL, `make check-mobile`, web build и Playwright,
goldens после визуального просмотра, проверки production Compose/scripts,
локальный Docker smoke нового комплекта. Remote Actions и реальный VPS
не объявлять проверенными без запуска. APK — тестовая подпись, новая версия.

## Передача работы

Агент menu — каталог, режимы и маршруты/тесты UI; агент deploy — отдельный
production-комплект и CI/CD; основной — настройки адреса, интеграция, приёмка,
документы решений и сборка. Один файл изменяет один владелец. Все прежние
незакоммиченные изменения пользователя и выполненных срезов сохраняются.

## Результат

Выполнены Flutter-анализ/8 core/107 app тестов, Node check с PostgreSQL,
5 lifecycle тестов и настоящий isolated production Docker smoke. Независимое
ревью закрыло воспроизведённую гонку навигации. Web bundle проверяется по
13 обязательным assets; новая debug APK 0.1.0+3 доступна для установки.
[Итоги и ограничения](../STATUS.md), [настройка VPS](../deploy/PRODUCTION.md).
Физическая приёмка и реальный GitHub/VPS deploy не выполнялись.
