# План: PB-031 — «Шкала терпения» и рабочий процесс команды

## Результат

Компания из 4–12 человек проходит новую игру на отдельных телефонах в существующей
комнате: каждый становится героем, тайно упорядочивает четыре неприятности,
остальные угадывают место скрытой карточки, видят раскрытие и получают очки.
После полного круга приложение показывает победителей и позволяет повторить игру.
Источник идеи — [план пользователя](../../Partybox-igry.md).

## Границы и зависимости

Поручение пользователя от 2026-11-21 разрешает выбрать одну новую механику и сначала
подготовить эффективный рабочий процесс с сабагентами и памятью проекта. PB-030
«Объясни слово» остаётся отдельной будущей задачей; PB-031 выполняется перед ней.

Существующие Flutter/NestJS/PostgreSQL/Socket.IO сохраняются. Новая игра работает
по протоколу v3; v1/v2 остаются совместимыми. Правила авторитетны на сервере,
Flutter отвечает за взаимодействие и отображение. Локального Pass & Play для новой
игры в этом срезе нет: исходный план предполагает отдельные телефоны.

Рабочие допущения: полный круг по порядку входа, один раунд на участника,
одно очко за точное место, герой очков в своём раунде не получает. Таймера нет:
обсуждение продолжается до закрытых ответов всех остальных. Ведущий переводит
раскрытие в следующий раунд или общий итог; при зависшем участнике можно отменить
партию. Выход отменяет партию, потеря связи сохраняет место.

## Проверка

`npm run doctor`, `npm run context -- tolerance`, `npm run context:check`,
`npm run check` с отдельной тестовой PostgreSQL 16, `make check-mobile`,
web build и доступное в окружении браузерное прохождение.
Результаты: doctor в строгом режиме проходит, карта 9 модулей/13 связей валидна.
Общий npm check с PostgreSQL: 20 backend + 10 contracts + 3 content теста,
без пропусков. Make check-mobile: 8 core + 84 app, один opt-in пропущен в общем
прогоне и затем отдельно успешно выполнен четырьмя настоящими Dart-клиентами.
Web release проходит; в Chrome на 390×844 пройдены первые два раунда через HTTPS,
ошибок консоли нет. Полный круг, итог и передача ведущего проверены real-client
тестом. После правки текста отдельно повторены четыре room screen теста.
[Снимки и пределы визуальной проверки](../design/pb-031/verification.md).
Docker HTTPS smoke также прошёл: сборка образа с новой колодой, проверенный TLS,
readiness, restart backend, outage/recovery БД и полный Dart-цикл обеих игр через
HTTPS. Его временные контейнеры/тома/секреты удалены. Физические телефоны,
screen reader, haptics и iOS/native build остаются открытыми; публичного размещения нет.

## Передача работы

Разделение: агент workflow — инструкции/граф/скрипты; backend — контракты,
контент и сервер; mobile — Flutter; основной агент — спецификация, окружение,
интеграция и проверка. Сабагенты возвращают изменённые файлы, команды проверки
и открытые ограничения. Секретные карточки и пользовательские данные в память
проекта не включаются. Предыдущие изменения переименования сохраняются.

Итог: сценарий и независимое ревью завершены. Исправлен P2 входа нового участника
после finished, добавлена PostgreSQL-регрессия. Коммит/публикация не выполнялись.
Следующий срез — PB-030, отдельная задача.
