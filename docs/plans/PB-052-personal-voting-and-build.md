# План: PB-052 — личное голосование и актуальная сборка

## Результат

Читаемая кнопка «Показать QR-код», личный голос каждого участника сетевого
«Шпиона», APK и web с иллюстрациями PB-051 и движением внутри сцен.
Дизайн-система — существующий «Полночный клуб».

## Границы и зависимости

Пользователь подтвердил голосование на каждом телефоне. Обратимые допущения:
голос закрытый и неизменяемый, голосуют все (включая шпиона и ведущего), выбор
себя разрешён; результат после всех голосов, побеждает кандидат с наибольшим
числом голосов. Ничья запускает новый тур среди лидеров, без раскрытия ролей.
Отключившегося ждут; явный выход отменяет партию по прежним правилам.
Локальная игра с одним телефоном сохраняет устное голосование.

rooms-v5 добавляет `spy.ballot {round, suspectId}`, публичный прогресс
`game.voting {round, candidateIds, votedIds}` и только собственный
`privateState.ballot {round, suspectId}`. Ранее начатые партии остаются устными.
Новая партия требует v5 всех участников. v1–v4 не могут подменить личные голоса
командой ведущего. Секретные команды не сохраняются в клиентском хранилище.

## Шаги

- Высокая сложность: backend/контракты → gpt-6.2-astra high; агент остановился
  по лимиту до правок, реализацию завершает ведущий.
- Средняя сложность: QR/сцены → gpt-6.2-sol medium; причина QR и правки сцены
  получены до лимита агента, интеграцию и проверки завершает ведущий.
- Ведущий: Flutter, интеграция, проверки, документация, локальные APK/web.
- [x] Контракт и серверное голосование.
- [x] Flutter, QR и движение сцен.
- [x] Проверки полного сетевого цикла и приватности.
- [x] Актуальные сборки и статус.

## Передача работы

Публикация, коммит и push в эту задачу не входят. Для голосования на production
требуется отдельно обновить backend до v5. Корневые APK теперь содержат PB-051
и PB-052; локальные режимы доступны без сервера. Web готов к существующему CD.
