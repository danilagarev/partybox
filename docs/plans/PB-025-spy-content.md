# План: PB-025 — темы и разнообразие «Шпиона»

## Результат

Компания выбирает одну из трёх тем по 24 локации в локальной или сетевой игре.
Локации не повторяются до прохода набора, на границе циклов нет немедленного
повтора. Короткие примеры вопросов помогают начать обсуждение.

## Границы и зависимости

Пользователь согласовал развитие приложения до VPS: контент «Шпиона» → локальная
«Объясни слово» → общий состав компании и навигация → полировка → обновляемый
контент → плейтест и внешний онлайн. Работаем по одному проверяемому срезу.
В этом срезе наборы встроены и доступны без интернета; загрузок, платежей и
обновления удалённого контента нет. JSON-наборы сохраняют формат 1; базовый набор
получает версию 2. Локальная история живёт в памяти адаптера, сетевая — приватно
в комнате PostgreSQL, включая отмену раунда и рестарт. Она не попадает в snapshot,
телефонное хранилище или логи. Старые комнаты без истории поддерживаются.

## Проверка

`npm run check` с PostgreSQL, `make check-mobile`, визуальный просмотр изменённых
экранов; реальные HTTP/Socket.IO и Docker HTTPS smoke при доступном окружении.
Физические устройства и VPS остаются отдельным этапом.
