# План: PB-055 — «Не может быть!»

## Результат

Игра для 2–12 человек: десять утверждений, тайный первый ответ, обсуждение,
окончательный ответ со ставкой 1–3, раскрытие объяснения и источника, общий счёт.
Выбор одной/нескольких из шести тем или смешанной партии. Общий телефон офлайн
и отдельные телефоны через комнаты; общий Flutter Android/iOS/Web.

## Границы и зависимости

Подтверждены пользователем: новая игра «Правда с подвохом», смешение смешного
и познавательного содержания, разделение на темы. Рабочее отображаемое имя —
«Не может быть!». 180 карточек (30 на тему), 10 раундов, 2–12 участников,
нет таймера/выбывания, ставка прибавляется/вычитается, отрицательный счёт допустим —
обратимые допущения согласованного предложения. Повторы исключены внутри партии.
Офлайн на общем телефоне приватность обеспечивается экранами передачи устройства.
Сеть авторитетна, rooms-v6 сохраняет v1–v5. Нет публикации/коммита без поручения.

### Контракт интеграции

Game ID `truth`, темы `animals`, `human`, `food`, `history`, `science`, `everyday`.
Контент `packages/game-content/packs/truth-ru-base.json`: schemaVersion=1,
id=truth-ru-base, gameId=truth, locale=ru, version=1, title, topics[{id,title,description}],
items[{id,topic,statement,truth:boolean,explanation,sources:[{title,url}],checkedAt}].

V6 расширяет V5: publicState.truth, privateTruth (обязательные nullable).
Truth public: sessionId, phase `initial|discussion|betting|reveal|finished`,
roundIndex (0–9), roundCount=10, topic, statement, initialAnsweredIds, betIds,
scores[{playerId,score}], result:null либо {truth,explanation,sources,
answers:[{playerId,initialAnswer:boolean|null,answer:boolean|null,stake,points}]}, winners.
Private: null вне initial/discussion/betting; иначе {initialAnswer:boolean|null,
answer:boolean|null,stake:number|null}. Никаких исходных ID карточки, объяснения,
ссылок или истины до reveal; баллы меняются только после последней ставки.

Команды с обычным sessionId/expectedVersion: truth.start {topics:string[]}
(пустой список = все), truth.initial {answer:boolean}, truth.discussed {},
truth.bet {answer:boolean,stake:1..3}, truth.next {}, truth.cancel {}.
После всех initial автоматически discussion; ведущий переводит в betting;
после всех bet — reveal и однократный подсчёт. Ведущий next после reveal,
после десятого finished. Менять первый/финальный ответ после отправки нельзя.
Выход во время партии отменяет её по существующей модели комнат.

## Шаги

- Высокий риск (приватность/транзакции/совместимость) → gpt-6.2-astra/high:
  backend и game-contracts, кроме схемы контента; полный сетевой цикл/незаконные команды.
- Средняя сложность → gpt-6.2-sol/medium: Flutter комнаты/каталог и тесты;
  без core, local UI и generated-файлов. Приёмка: v6 и новый игровой экран.
- Средняя сложность → gpt-6.2-sol/medium: 180 карточек, схема контента/тесты;
  первоисточники, шесть тем по 30, правда и выдумка с пояснениями.
- Ведущий: чистый Dart/local shared-phone UI, интеграция, документация и проверки.
- Независимое сетевое ревью после реализации.

## Проверка

- `npm run check` с изолированной PostgreSQL 16: 74 теста без пропусков,
  включая совместимость v1–v5, повтор ставки, запрет старой команды после смены
  раунда, рестарт сервера и восстановление персонального snapshot по Socket.IO.
  Лог `/tmp/partybox-pb055-check-node.log`.
- `make check-mobile` с локальным backend: 18 тестов ядра и 165 тестов приложения
  без пропусков. Два и двенадцать Dart-клиентов прошли по десять раундов
  через HTTP/Socket.IO, затем покинули комнаты. Покрыты общий телефон, уход
  с личного экрана в фон, экран итогов и обработка неопределённого результата
  отправки ставки. Лог `/tmp/partybox-pb055-check-mobile.log`.
- Два независимых просмотра сетевого пути нашли регрессии выхода старого клиента
  и показа итогов при входе из другой игры. Обе исправлены и покрыты тестами.
  При быстрой игре двенадцати клиентов убраны лишние переподключения между
  отправкой решения и получением полного персонального snapshot.

- Flutter Web release собран в `apps/mobile/build/pb055-web/`. Staging и сверка
  контрольных сумм прошли во временной папке. Все 180 карточек в asset
  побайтно совпали с исходным набором. Лог `/tmp/partybox-pb055-web.log`.

## Передача работы

180 карточек, по 30 на тему, с объяснениями и источниками. Обложка и экраны
используют «Полночный клуб». При явном откате клиента со старым токеном
поддержка v6 остаётся записанной для этого участника. С v1–v5 он может выйти,
а отвечать в партии сможет после возврата на v6. Публичный деплой и физическая
проверка на телефонах не выполнялись. Новая серверная версия не требует миграции.
