# PB-047 — PartyBox: интерфейс, контент и проверочная release-сборка

## Результат

Две игры доступны из каталога. В «Шпионе» поднятая пальцем обложка открывает
только соответствующую полосу личной карточки, без скачка размера и автоматического
раскрытия. Для проверки на телефоне выдаётся оптимизированный APK с прежней подписью.

## Границы и зависимости

Подтверждено пользователем: название PartyBox, допустимы взрослые темы.
Выбраны взрослые бытовые и социальные ситуации без explicit-контента.
Контакты разработчика и политика конфиденциальности по его указанию остаются
незавершёнными. Публикация в магазинах и создание ключей не выполняются.

Команда: root — жест, совместимость сетевого контента и общая проверка;
design_release — дизайн/иконки/goldens; content_release — наборы и контентное
ревью; release_readiness — signing, store-аудит, независимые проверки.
Один файл в каждый момент меняет один исполнитель; Flutter запускается последовательно.

## Проверка

`make check-mobile`, `TEST_DATABASE_URL=… npm run check`,
`node deploy/smoke.mjs`, `node deploy/production/test-smoke.mjs`.
Результаты, размеры артефактов и физические ограничения — в STATUS и
[release-аудите](../release/PB-047-readiness.md).

## Передача работы

Для Android сохраняется существующий app ID и сертификат тестовых установок.
Магазинная подпись обязательна в обычном release; тестовая разрешается явным
флагом. iOS требует отдельной проверки на macOS/Xcode. Не считать браузерные
и widget-тесты проверкой реальных устройств или одобрением магазинов.
