# План: PB-040 — HTTPS и подготовка физической приёмки

## Результат

Воспроизводимый запуск одного backend с PostgreSQL и HTTPS для четырёх телефонов.
Локально проверяем образ, миграцию, readiness, перезапуск, сертификат и полный
раунд. На VPS остаётся указать домен/сервер; физическую приёмку не подменяем CI.

## Границы и зависимости

Сетевой срез зафиксирован в 72f83d0. По поручению пользователя продолжить PB-040.
Рабочий вариант — собственный VPS, Docker Compose и Caddy. Внешнего доступа,
доменов и покупок не создаём. Один backend-процесс. Секреты отдельными файлами,
приватная БД, миграция до готовности приложения, TLS на Caddy.

## Шаги

- [x] Docker image с ограниченным build context, непривилегированный runtime.
- [x] Compose PostgreSQL → migration → backend → Caddy, secrets и volumes.
- [x] Readiness отдельно от health; очистка истёкших комнат/лимитов.
- [x] Явно настраиваемый один доверенный proxy для IP-лимитов HTTP/Socket.IO.
- [x] Локальная HTTPS-проверка: четыре клиента, restart и сохранение сессии.
- [x] Инструкция VPS, резервное копирование, обновление и физический протокол.

## Проверка

Node check с PostgreSQL, Docker build/config и локальный Compose с внутренним CA.
Flutter network smoke использует явный тестовый CA, без отключения TLS-валидации.
Публичное HTTPS и физические Android/iOS требуют сервера и устройств пользователя.

## Передача работы

Комплект реализован и проверен Docker smoke с Node и четырьмя Dart-клиентами
по HTTPS. Отказ без доверия тестовому CA проверен; валидация TLS не отключается.
Проверены restart backend, outage/restart PostgreSQL, сохранение сессии и дедлайна,
результат/retry и защита IP-лимита от поддельного forwarded header. Отдельный job
https добавлен в CI; удалённый запуск Actions в этой сессии не выполнялся.
[Инструкция VPS](../deploy/VPS.md), [физический протокол](../playtests/PB-040-network.md).
Секреты smoke и его volumes удалены. Внешнего развёртывания/push не было.
Мобильные правила и wire-контракты на этом этапе не менялись.
Следующий шаг требует VPS/домена и четырёх реальных телефонов.
