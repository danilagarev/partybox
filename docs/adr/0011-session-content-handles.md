# ADR 0011 — идентификаторы ситуаций внутри партии

Статус: принято 2026-11-21, PB-047.

## Контекст

Исходный набор «Шкалы терпения» вырос до 220 ситуаций. Схема контента допускает
двух- и трёхзначные номера, но установленные клиенты rooms-v3 принимают только
`tolerance-[0-9]{2}`. Передавать новые исходные ID напрямую несовместимо.

## Решение

После перемешивания сервер выбирает 4 ситуации на участника (16–48) и назначает
непрозрачные идентификаторы `tolerance-01`…`tolerance-48` в рамках новой сессии.
Тексты сохраняются. Исходные ID и невыбранный контент остаются внутренними.
Команды адресуют карточку в контексте sessionId; wire-контракт rooms-v3 не меняется.

## Последствия

Старые APK понимают расширенный серверный контент. Между сессиями handle не
является постоянным идентификатором ситуации; для будущей аналитики потребуется
внутренняя связь с source ID, если возникнет конкретное требование.
Тесты проверяют уникальность выбранных текстов/handle и соответствие wire-схеме.
