# ADR 0005 — серверная партия «Шпион»

Дата: 2026-11-08. Статус: принято для PB-040; продуктовые допущения ниже остаются рабочими.

## Решение

Сетевые команды и проекции имеют версию 2 и отдельные HTTP endpoints /v2/rooms.
Версия 1 остаётся совместимой с лобби. Новый клиент восстанавливает прежний токен;
чтение v2 отмечает поддержку игры. Начать партию можно, когда все активные
участники используют v2. Незавершённая регистрация v1 повторяется через API v1.

Авторитетные правила — чистые TS-функции с явно переданными временем, составом,
локацией и индексом шпиона. Совместимые JSON-векторы проверяют их с Dart SpySession.
Сервер использует криптографическую случайность, фиксирует версию встроенного
пакета, ID партии, секретное состояние и readyIds в PostgreSQL. Полное состояние
никогда не попадает в публичную проекцию; личная карточка строится по actor token.

Рабочие допущения для первого сетевого среза: каждый подтверждает свою карточку
независимо от порядка; после всех подтверждений начинается обсуждение. Устное
голосование остаётся общим, ведущий подтверждает подозреваемого. Встроенного
голосового чата нет. Ведущий запускает, завершает обсуждение, подтверждает выбор
и может отменить раунд. Новый участник входит только в лобби/после результата.
Явный выход во время раунда отменяет его и возвращает оставшихся в лобби;
ведущий передаётся по согласованному порядку. Disconnect ничего не отменяет.

Команда содержит sessionId (null до партии), commandId и expectedVersion. Повтор
принятой команды возвращает прежний ack до проверки текущей версии/фазы. Другой
payload с тем же ID отклоняется. Дедлайн проверяется на сервере при чтении/командах
и фоновым проходом, восстанавливается после рестарта из БД. Таймер Flutter только
рисует остаток по serverTime, окончание решает сервер.

Мобильный клиент хранит только доступ и незавершённую команду, без snapshot/ролей.
Контейнер RoomAccess записывается с schemaVersion=2; версия 1 читается совместимо
под прежним ключом хранилища, сохраняя идентичность незавершённых запросов.
Показ роли — локальное отдельное действие; фон, disconnect, назад и команды
немедленно скрывают карточку. Повтор после неопределённого ответа сохраняет ID;
конфликт версии требует нового осмысленного действия после snapshot.
