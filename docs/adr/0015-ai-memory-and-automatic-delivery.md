# ADR 0015: локальная память и автоматический production CD

Принято 2026-11-23 по запросу полного workflow с экономией токенов.
Заменяет ручной-only trigger ADR 0010; топология VPS/ingress сохраняется.

## Решение

- `AGENTS.md` маршрутизирует к карте/плану, канонические требования остаются в docs.
- Serena 2.1.0 запускается локальным wrapper через uv, без глобальной установки.
  Markdown-память содержит ссылки; LSP помогает читать нужные символы.
  Приложение, CI и CD не зависят от доступности Serena.
- Runner проверок сохраняет логи и fingerprint-квитанции; успешные проверки
  автоматически не пропускаются. Это снижает объём вывода, а не объём тестирования.
- Успешный Checks push main из этого репо запускает CD. Точный SHA и артефакт
  успешного HTTPS run/attempt проверяются до сборки и выдачи production secrets.
  Устаревший run не должен автоматически переиздавать старую версию.
- Ручной CD проверенного main SHA остаётся для redeploy/rollback. Image закреплён
  digest; миграции выполняются до замены, readiness rollback сохраняется.
  Откат image не откатывает БД: миграции должны быть обратно совместимы.

## Последствия

Требуются uv/Python и первоначальная загрузка LSP только для Serena; новые MCP
инструменты требуют подключения в клиенте. Экономия токенов оценивается на задачах,
не обещается по факту установки. GitHub protection rules и secrets — внешние
настройки; наличие workflow в Git не доказывает успешный production deploy.
