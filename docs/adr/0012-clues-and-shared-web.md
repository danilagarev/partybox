# ADR 0012 — «Что объединяет?» и общий Flutter Web

Принято: 2026-11-22. PB-048.

## Контекст

Нужна одна игра для одиночного прохождения и компании, а также доступ ко всем
играм через браузер. Пользователь выбрал общий Flutter-клиент вместо отдельного
React-интерфейса. Старые APK с протоколами 1/2/3 должны продолжать работать.

## Решение

«Что объединяет?» (`clues`) имеет пять заданий по четыре подсказки. Одиночные
правила находятся в чистом Dart, сетевые — в чистом TS. Общие JSON-векторы
проверяют нормализацию русских ответов. ИИ/fuzzy matching не используются:
принимаются canonical answer и авторские aliases после одинаковой нормализации.

Сеть использует rooms-v4 с отдельными `clues` и `privateClues`. Комната допускает
1–12 игроков для этой игры; минимум 4 у прежних игр сохранён. Сервер хранит полный
выбранный контент в JSONB и не рассылает неоткрытые подсказки/ответы. В playing
личная проекция содержит последнюю собственную попытку, в reveal/finished равна
null. Ответы раскрываются публично только на результате. SQL-миграций нет.

Секретный `clues.answer` не сохраняется в RoomVault. Определённый VERSION_CONFLICT
позволяет ограниченно повторить тот же ответ только в той же сессии/раунде/подсказке;
неопределённая сеть вызывает синхронизацию без автоматического повтора.

Для v4 HTTP чтения/команд один IP имеет предел 720/мин, каждый guest —120/мин.
Socket v4:360/мин на IP и 60/мин на подтверждённого гостя. Это позволяет компании
играть за одним NAT; create10/join30 и старые лимиты 1/2/3 не ослабляются.
Идентификаторы лимитов хешируются HMAC; сырой guest token в таблицу не попадает.

CI собирает Flutter Web release с same-origin и browser rooms, без внешнего CDN.
Полный список публичных файлов, включая движок CanvasKit, проверяется хешами.
Точный артефакт успешного Checks на выбранном main SHA входит в Docker-образ
backend. Nest раздаёт только разрешённые файлы WEB_ROOT; Caddy и один origin
обслуживают статику, HTTP и Socket.IO. Нового контейнера/порта на VPS не требуется.
API не заменяется HTML fallback и не кешируется. JS/HTML имеют no-store;
assets переиспользуются после HTTP-ревалидации, чтобы обновления не смешивали версии.

## Последствия и ограничения

Локальный «Шпион» и solo clues работают без сервера в нативном приложении.
Веб — онлайн-сборка: manifest/icons дают способ добавить ярлык, но offline cache
не обещается. Service worker не регистрируется. Доступ к комнате остаётся
привязанным к browser tab через sessionStorage; закрытие вкладки может его удалить.

Контент solo находится в клиентском bundle. Поэтому сеть защищает приватность
проекций и честность начисления очков, но не обещает защиту от игрока, который
намеренно изучает исходный набор. Это подходит для игры знакомых без денежных ставок.

Публичный сервер обновляется отдельным CD после зелёного Checks; локальная
сборка приложения не меняет VPS. iOS и физические устройства проверяются отдельно.
