# ADR 0008: браузерный запуск для друзей

Статус: принято для PB-041, 2026-11-21.

## Контекст

Пользователю нужна возможность сыграть существующего «Шпиона» с отдельных
телефонов по Wi-Fi, а также через интернет. Публичный сервер пока не развёрнут,
тестовые APK не содержат готового внешнего адреса. Нужен воспроизводимый способ
проверить игру без Android/iOS-установки и macOS.

## Решение

Добавить локальный launcher: отдельная временная PostgreSQL, существующий backend,
Flutter web, статические файлы и HTTP/Socket.IO proxy на одном origin. Снаружи
доступен только порт приложения. При завершении удалить только свои ресурсы.
Команды не печатают токены, закрытые роли и пароли; runtime-секреты не пишутся в Git.

LAN собирается в profile и допускает HTTP в доверенной сети. Интернет собирается
в release, требует HTTPS и использует явно запускаемый cloudflared Quick Tunnel.
Туннель — временный способ провести игровой вечер, не постоянный production.
Адрес меняется при перезапуске, компьютер должен оставаться включённым.
Для стабильного адреса применим существующий VPS/HTTPS-комплект.
Запуск LAN не публикует игру через интернет. Firewall, роутер и DNS автоматически
не изменяются. Оба web режима используют ROOM_SERVER_URL=same-origin.

Явный BROWSER_ROOMS=true включает браузерный RoomVault, в release только на HTTPS.
Он сохраняет RoomAccess в sessionStorage отдельным ключом, без snapshot/ролей,
не используя shared_preferences для токенов. Обновление той же вкладки сохраняет
место. Ошибки чтения и очистки не скрываются: нельзя автоматически регистрировать
ещё одного игрока поверх неизвестного доступа. Закрытые команды «Шкалы терпения»
по-прежнему запрещено сериализовать. Обычное web-превью остаётся в памяти,
native использует прежний secure storage.

Подтверждение роли «Шпиона» после известного VERSION_CONFLICT автоматически
повторяется в той же сессии, если собственная готовность ещё не принята. Число
попыток ограничено составом комнаты. Команда с неопределённым ответом сохраняет
свой ID; остальные действия требуют прежней явной обработки конфликта.
Серверная проверка версий, ролей и фаз не ослабляется.

## Основания и ограничения

SessionStorage переживает reload в той же вкладке и разделяется по origin и
контексту вкладки; браузерное восстановление закрытых вкладок зависит от браузера.
Не обещаем восстановление после удаления данных/закрытия браузера.
[MDN: sessionStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/sessionStorage).

Quick Tunnel не требует аккаунта или домена, предоставляет временный публичный
адрес и не гарантирует доступность; ссылка доступна любому, у кого она есть.
Комната дополнительно требует PIN, личные проекции — токен участника.
[Cloudflare: Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/).
Версии инструментов и ссылки сверены 2026-11-21. Для физического вечера нужно
проверить доступность адреса с телефонов; это не заменяется localhost-тестом.

Локальный proxy сам перезаписывает X-Forwarded-For адресом TCP-клиента и backend
доверяет ровно одному этому proxy. В LAN входящие XFF/CF-заголовки не определяют
адрес. В internet listener привязан только к loopback, а CF-Connecting-IP
принимается только при явном режиме туннеля и только как один валидный IP.
Это сохраняет независимые IP-лимиты и не доверяет поддельной цепочке клиента.
[Cloudflare: HTTP headers](https://developers.cloudflare.com/fundamentals/reference/http-headers/).
