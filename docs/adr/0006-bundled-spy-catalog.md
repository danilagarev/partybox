# ADR 0006 — каталог тем и приватная ротация «Шпиона»

Дата: 2026-11-08. Статус: принято для PB-025.

## Решение

В `game-content/spy-catalog.json` находится общий каталог формата 1: gameId,
locale и записи id/version/description. Названия и локации остаются в JSON-наборах
формата 1; версия «Знакомых мест» повышается до 2 при расширении содержимого.
Каталог и все его наборы входят во Flutter assets и backend image. Схемы находятся
в game-contracts; тесты проверяют совпадение версий, полноту assets и уникальность.
Это встроенный каталог, ещё не формат удалённых обновлений PB-050.

`spy.start.payload.packId` в протоколе 2 расширен с одного значения до устойчивого
ID. Поля, ответы и protocolVersion не меняются: прежняя команда с spy-ru-base
по-прежнему принимается. Сервер проверяет наличие ID в своём каталоге, неизвестный
набор даёт INVALID_REQUEST. Generated TS/Dart/OpenAPI обновляются инструментом.
Новое приложение с темами требует обновлённый backend; старые клиенты с базовым
набором совместимы. Активная партия хранит локацию и packVersion, поэтому обновление
встроенного контента не меняет уже розданные карточки.

Локация выбирается равновероятно среди ещё не использованных в текущем проходе
набора. После исчерпания начинается новый проход, первый выбор исключает последнюю
локацию предыдущего. Набор из одной локации остаётся допустимым. Истории независимы
по id/version. Сервер использует CSPRNG и сохраняет историю вместе с игровой
командой и ack в одной транзакции. Повтор commandId не расходует следующую локацию.
Отмена и выход не стирают историю комнаты; при новой версии набора старый проход
сбрасывается. Старые JSONB-комнаты без истории продолжают работать без миграции.

История — приватное поле комнаты, не часть контракта/snapshot. Она удаляется вместе
с комнатой по TTL и ограничена числом текущих наборов и их размером. На телефоне
история локальных раундов остаётся в памяти адаптера до выхода из игрового экрана;
после закрытия/перезапуска новый проход. Подготовка формата 1 уже содержит packId
и восстанавливает его, неизвестный набор заменяется доступным с уведомлением.

Подсказки обсуждения одинаковы для всех тем и ролей и не получают игровую сессию.
