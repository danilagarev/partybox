# ADR 0014 — «Не может быть!» и rooms-v6

Принято в PB-055.

Новая игра пользуется общим лобби, транзакциями, квитанциями команд, TTL и
персональной рассылкой rooms. В офлайн-режиме чистый Dart принимает уже
перемешанную колоду и ведёт передачу телефона. Flutter использует систему
«Полночный клуб» для обоих режимов. Онлайн сервер выполняет независимые чистые
TS-правила. Общая колода и её схема живут в пакетах контента и контрактов.

Публичная проекция v6 до раскрытия включает текст, тему и прогресс. Личная
проекция показывает только собственный выбор. Ставки влияют на общий счёт
атомарно при принятии последней. Результат, объяснение и ссылки появляются после
этого же коммита. Колода включена в офлайн-приложение, поэтому участник с доступом
к исходному набору может заранее посмотреть ответы. Приватность сетевого
протокола защищает ответы участников и содержимое текущей партии в snapshot.

Rooms-v6 добавляет поля и команды к v5. Поддержка v6 проверяется у каждого
участника перед стартом. Существующие комнаты и JSONB-данные не требуют миграции.
Параллельные решения принимаются только для версии текущего этапа и ID партии.
Точные повторы получают прежнюю квитанцию. При потере ответа мобильный клиент
перечитывает состояние. Выход участника завершает текущую игру по правилам
общей комнаты. Временный обрыв подключения сохраняет место и решения.
