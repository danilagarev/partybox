# ADR 0007: «Шкала терпения» и протокол v3

Статус: принято для PB-031, 2026-11-21.

## Контекст

[План пользователя](../../Partybox-igry.md) добавляет игры для отдельных телефонов.
Для второй реальной сетевой механики нужны закрытые действия участников,
отличающиеся от выдачи ролей «Шпиона». Существующие клиенты v1/v2 должны продолжить
работать, не получая неподдерживаемую игровую проекцию.

## Решение

«Шкала терпения» имеет собственные чистые TS-правила и сохраняемое состояние в
JSONB комнаты. Команды проверяет сервер; время и случайный выбор карточек не
вычисляются внутри правил. Универсальный игровой движок не вводится.

Новые HTTP endpoints и Socket.IO auth используют protocolVersion=3. Публичная
часть содержит отдельное поле tolerance, личная — privateTolerance. Старые
форматы «Шпиона» сохраняются. Для старта новой игры все активные участники должны
подтвердить поддержку v3. В комнате одновременно идёт одна игра.

Публичны исходные четыре карточки, герой, целевая карточка, три видимых позиции,
факт получения ответов и счёт. Полная сортировка до раскрытия принадлежит только
герою. Ответы до раскрытия доступны только их авторам. Подбор цели не зависит
от тайной сортировки. Результат и очки появляются атомарно после последнего ответа.

Принятые команды и состояние сохраняются одной PostgreSQL-транзакцией, повтор
с прежним commandId возвращает прежний ack. Перезапуск сохраняет партию, обрыв
связи не меняет состав, явный выход отменяет партию и передаёт ведущего.

## Закрытые действия на телефоне

Сортировка и догадка не записываются в SecureRoomVault даже как payload ожидающей
команды. Они отправляются из памяти; при неопределённом ответе клиент перечитывает
личную проекцию. Уже принятое действие видно в ней. Если действие не принято,
участник подтверждает его снова явно после синхронизации. Сервер запрещает второй
ответ в том же раунде. Остальные команды используют существующую стратегию retry.

Фон, потеря связи и уход с экрана скрывают тайные данные. Черновик сортировки
удаляется; восстановить принятый порядок герой может через личную проекцию.

## Последствия

Клиенты v1/v2 и прежние сохранения доступа поддерживаются отдельно. Новый контракт
имеет схему, примеры, generated TS/Dart и OpenAPI. Dart-ядро не дублирует новую
сетевую механику: локального режима для неё пока нет. PB-030 остаётся в backlog.
