# PB-040 — приёмка на четырёх телефонах

Статус: протокол подготовлен, физический прогон не выполнен.
Нужны 4 Android/iOS-устройства с одной версией приложения и одинаковым HTTPS
backend. [Запуск сервера и сборка](../deploy/VPS.md). Фиксировать только обезличенные
модели/ОС, версию APK/IPA, шаги и дефекты. Не записывать токены, роли и локации.

## Сценарий

1. Устройство A создаёт комнату, B/C/D входят по коду. На всех ровно 4 участника;
   собственное место и ведущий отмечены. Общий Wi-Fi не мешает входу.
2. A выбирает время и запускает. Каждый открывает только свою карточку, затем
   скрывает/подтверждает. Таймер стартует только после всех подтверждений.
3. На одном устройстве при открытой карточке уйти в фон и вернуться: карточка
   закрыта. Включить/выключить авиарежим: секретный текст исчезает при disconnect,
   после восстановления место и раунд сохраняются, карточка остаётся закрытой.
4. Во время обсуждения закрыть приложение на одном телефоне и открыть комнату
   снова: прежний участник, без повторной регистрации. Уйти в фон до истечения
   deadline; после возвращения показать текущую фазу сервера.
5. Ведущий заканчивает обсуждение или ждёт таймер; только он вводит общий выбор.
   Все видят одинаковый результат. Начать ещё раз: новый раунд, прежний состав.
6. Перезапустить backend во время раунда. На телефонах скрываются карточки при
   потере связи; после reconnect сохраняются sessionId/фаза/дедлайн без новой раздачи.
7. Ведущий явно выходит: активный раунд отменяется, остальные видят лобби,
   управление у следующего по порядку входа. Последний выход закрывает комнату.
8. Проверить native secure storage после force-stop/запуска, маленький экран,
   крупный шрифт, клавиатуру, TalkBack/VoiceOver, reduced motion, haptics и свайп назад.
