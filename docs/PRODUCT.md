## Первый пользовательский сценарий

Каталог → правила «Шпиона» → имена игроков → настройки → экран передачи телефона →
личная роль → скрытие роли → следующий игрок → обсуждение с таймером → выбор
подозреваемого → раскрытие → новая партия с прежними именами.

Запуск после знакомства с приложением целимся уложить в 30 секунд. Правила должны
помещаться на одном коротком экране. Это цели для плейтеста, а не уже измеренные метрики.

## До публичного релиза нужно решить

1. Финальное название, reverse-domain ID и владелец developer accounts.
2. Обязателен ли онлайн в первой store-версии; состав первых игр и языков.
3. Аудитория, возрастные темы, права на названия, тексты и иллюстрации.
4. Платные наборы, восстановление покупок, аналитика и обработка данных.

Сроки 4–7 и 9–14 недель в исходной беседе — предварительные оценки ассистента.
Новый календарный план составляется после первого плейтеста и уточнения релизного объёма.

## Уточнение PB-042 — 2026-11-21

Пользователь не нашёл вторую игру и поручил переработать меню и подготовить
backend CI/CD на свой существующий VPS за Nginx. Обе реализованные игры должны
быть видны сразу, с отдельными правилами и доступными режимами.
Вход по коду общий; адрес сервера меняется без пересборки приложения.
PartyBox размещается отдельным Docker-проектом под своим поддоменом рядом
с текущим backend. Настройку GitHub Secrets, DNS и VPS выполняет владелец
по инструкции; автоматический деплой следует только после успешного CI.
Поддомен и способ установки Nginx пока не подтверждены; пример рассчитан на Nginx хоста.

## Уточнение production PB-044 — 2026-11-21

PartyBox размещается отдельной папкой рядом с Baza на том же VPS. Входной Caddy
пользователь настроит отдельно: это самостоятельный Docker-контейнер вне Compose
приложений. Подтверждён домен partybox.sorima.tech. Общие только VPS и ingress;
БД/секреты/тома и частные сети приложений независимы. Интеграция в Nginx Baza
больше не является целевой схемой. CI/CD использует ручной production запуск
по образцу Baza и отдельное значение DEPLOY_PATH PartyBox.
