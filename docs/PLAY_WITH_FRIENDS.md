# Как сыграть с друзьями

Число участников зависит от игры. Для «Мутных сделок» нужно 2–6 человек,
для «Не может быть!» — 2–12, для «Шпиона» и «Шкалы терпения» — 4–12. Компьютер запускает сервер и остаётся включённым до конца
игры. У каждого свой телефон; устанавливать приложение для браузерного режима
не обязательно. На компьютере нужны Node из `.nvmrc`, Docker и Flutter из `.fvmrc`.
`npm run doctor -- --mobile` проверяет инструменты.

## Одна Wi-Fi сеть

Из корня проекта:

```sh
npm run play:lan
```

Дождитесь строки «Телефоны в той же Wi-Fi сети» и откройте указанный адрес на
телефонах. Адрес компьютера может изменяться. Если выбран не тот сетевой интерфейс,
задайте адрес явно: `npm run play:lan -- --advertise-host 192.168.1.241`.
При повторном запуске без изменений кода можно добавить `--skip-build`:
скрипт проверит режим и контрольные суммы сохранённой сборки.

Если страница не открывается с телефона, проверьте, что оба устройства находятся
в одной сети и роутер не изолирует гостей друг от друга. В Windows/WSL может
потребоваться разрешение входящего порта 8720 в firewall. Скрипт не меняет
firewall и настройки роутера автоматически. HTTP этого режима предназначен
для доверенной локальной сети.

## Через интернет

Нужен установленный [cloudflared](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/downloads/).
Он ищется в `CLOUDFLARED_BIN`, `.tools/cloudflared` или PATH.

```sh
npm run play:internet
```

Дождитесь строки «Ссылка для друзей» и отправьте её участникам. Это отдельная
release-сборка с HTTPS. Публичный туннель создаётся только этой командой;
запуск Wi-Fi его не создаёт. Для другого локального порта:
`npm run play:internet -- --port 8721`.

Адрес временный, меняется после нового запуска и перестаёт работать после
остановки. Доступность зависит от Cloudflare и подключения компьютера; постоянный
домен на VPS — отдельный вариант из [инструкции развёртывания](deploy/VPS.md).
Для удалённого обсуждения нужен отдельный голосовой созвон: приложение управляет
ролями и ходом игры, встроенного аудио нет.

## Партия «Шпион»

1. Ведущий открывает «Игры в комнате», вводит имя и создаёт комнату.
2. Друзья на том же адресе выбирают «Войти по коду», вводят свои имена и код комнаты.
3. Когда собрались хотя бы четверо, ведущий выбирает «Шпион», тему и время.
   Правила доступны прямо в лобби.
4. Каждый открывает свою карточку и подтверждает роль. Карточку можно потянуть
   вверх и удерживать либо открыть доступной кнопкой. До обсуждения видны имена
   тех, кто ещё не подтвердил готовность.
5. Обычные игроки знают одно место, шпион пытается не выдать себя. Задавайте
   вопросы о месте, не называя его. После таймера или досрочного завершения
   ведущим проголосуйте вслух; ведущий выберет подозреваемого и подтвердит выбор.
6. На результате раскрываются место и шпион. Можно сыграть снова с тем же
   составом или выбрать другую игру.

Перезагрузка той же браузерной вкладки сохраняет участие: снова нажмите
«Игры в комнате». Личная карточка после возврата закрыта. Закрытие вкладки,
удаление данных браузера или смена адреса могут потерять доступ; новый вход по
PIN не возвращает прежнюю роль. Фон и обрыв связи скрывают карточку и сохраняют
место. Явный выход отменяет текущую партию; уход ведущего передаёт управление.

Остановка Ctrl+C завершает стенд и удаляет только его временную БД. После
повторного запуска создайте новую комнату. Сборки сохраняются в игнорируемом
`output/play-lan/` или `output/play-internet/`, личные данные туда не записываются.

## Приглашение по QR

В лобби или между партиями нажмите «Пригласить друзей». Друг сканирует QR обычной
камерой телефона: открывается веб-версия с заполненным кодом, остаётся ввести имя.
Можно скопировать ссылку и отправить её самостоятельно. Ссылка не содержит роли
и данных входа. Если уже открыта другая комната, приложение предложит сохранить
участие или явно выйти перед новым входом. В текущую партию новые игроки не входят.

На компьютере открывайте стенд по LAN-адресу, а не localhost, чтобы QR работал
на телефоне в той же Wi-Fi сети. В публичной версии ссылка использует HTTPS-домен
сервера; для этого сначала опубликуйте обновлённый веб через CD.

## «Что объединяет?» и проверка одному

Выберите игру в каталоге: «Играть одному» открывает пять заданий без сервера.
После первой подсказки ответ стоит4 очка, затем3/2/1. Неверный ответ можно
повторить после новой подсказки; допустимые варианты заданы в наборе.

Для совместной партии создайте комнату «Что объединяет?» на1–12 участников.
Ведущий открывает подсказки для всех; ответы вводятся тайно. После раскрытия
видны очки, затем ведущий переводит к следующему заданию. На последней подсказке
«Открыть ответ» позволяет закончить раунд, если кто-то отошёл.

Для проверки одному откройте четыре независимые вкладки браузера на одном
адресе. В первой создайте комнату, в трёх остальных войдите по коду с разными
именами. Не дублируйте уже вошедшую вкладку: sessionStorage может скопироваться.
Все клиенты должны использовать один стенд; APK по умолчанию подключён к
публичному API. Для новой сетевой игры нужен backendv4.

Веб имеет manifest/icons и может добавляться на домашний экран. Уже загруженная
solo-партия продолжает работать без сети, но холодный offline запуск и сохранение
активной solo-партии после перезагрузки не обещаются. После публикации PB-048
через CI/CD общий каталог появится на https://partybox.sorima.tech/.

## Партия «Не может быть!»

1. Ведущий создаёт комнату и отправляет код участникам.
2. В лобби ведущий выбирает «Не может быть!» и темы. «Всё вперемешку»
   берёт карточки из всех шести тем.
3. Каждый даёт первый тайный ответ. Обсудите утверждение вслух или в созвоне.
4. Ведущий открывает ставки. Каждый повторяет или меняет ответ и ставит
   1–3 очка. После последней ставки все видят ответ, объяснение и счёт.
5. Ведущий листает оставшиеся раунды. После десятого открываются итоги.

## Партия «Мутные сделки»

В каталоге выберите «Мутные сделки», создайте комнату и передайте код или QR
остальным. Когда войдут 2–6 участников, ведущий запускает партию. Всем нужен
клиент с поддержкой v7 и сервер этой версии.

Каждый тайно выбирает цель и выставляет чемодан или пасует. Обсуждайте цены
вслух, а встречные предложения, проверки и покупки подтверждайте на своём
телефоне. Когда время торгов заканчивается, игроки без покупки могут выбрать
открытый лот. После пятого раунда откроются цели, содержимое проданных лотов
и итоговый счёт. Для локального веб-стенда используйте описанный выше LAN-режим.

Для первой партии вдвоём попробуйте выставиться оба. Если у одного есть товар
стоимостью 2, сделка за 3 со страховкой принесёт по одному очку выгоды обеим
сторонам при обычных условиях. Покупатель может предложить эту цену сам.
Потом попробуйте продать лот, о содержимом которого соперник пока только гадает.
