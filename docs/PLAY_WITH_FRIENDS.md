# Как сыграть с друзьями

Нужно 4–12 участников. Компьютер запускает сервер и остаётся включённым до конца
игры. У каждого свой телефон; устанавливать приложение для браузерного режима
не обязательно. На компьютере нужны Node из `.nvmrc`, Docker и Flutter из `.fvmrc`.
`npm run doctor -- --mobile` проверяет инструменты.

## Одна Wi-Fi сеть

Из корня проекта:

```sh
npm run play:lan
```

Дождитесь строки «Телефоны в той же Wi-Fi сети» и откройте указанный адрес на
телефонах. Адрес компьютера может изменяться. Если выбран не тот сетевой интерфейс,
задайте адрес явно: `npm run play:lan -- --advertise-host 192.168.1.241`.
При повторном запуске без изменений кода можно добавить `--skip-build`:
скрипт проверит режим и контрольные суммы сохранённой сборки.

Если страница не открывается с телефона, проверьте, что оба устройства находятся
в одной сети и роутер не изолирует гостей друг от друга. В Windows/WSL может
потребоваться разрешение входящего порта 8720 в firewall. Скрипт не меняет
firewall и настройки роутера автоматически. HTTP этого режима предназначен
для доверенной локальной сети.

## Через интернет

Нужен установленный [cloudflared](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/downloads/).
Он ищется в `CLOUDFLARED_BIN`, `.tools/cloudflared` или PATH.

```sh
npm run play:internet
```

Дождитесь строки «Ссылка для друзей» и отправьте её участникам. Это отдельная
release-сборка с HTTPS. Публичный туннель создаётся только этой командой;
запуск Wi-Fi его не создаёт. Для другого локального порта:
`npm run play:internet -- --port 8721`.

Адрес временный, меняется после нового запуска и перестаёт работать после
остановки. Доступность зависит от Cloudflare и подключения компьютера; постоянный
домен на VPS — отдельный вариант из [инструкции развёртывания](deploy/VPS.md).
Для удалённого обсуждения нужен отдельный голосовой созвон: приложение управляет
ролями и ходом игры, встроенного аудио нет.

## Партия «Шпион»

1. Ведущий открывает «Игры в комнате», вводит имя и создаёт комнату.
2. Друзья на том же адресе выбирают «Войти по коду», вводят свои имена и код комнаты.
3. Когда собрались хотя бы четверо, ведущий выбирает «Шпион», тему и время.
   Правила доступны прямо в лобби.
4. Каждый открывает свою карточку и подтверждает роль. Карточку можно потянуть
   вверх и удерживать либо открыть доступной кнопкой. До обсуждения видны имена
   тех, кто ещё не подтвердил готовность.
5. Обычные игроки знают одно место, шпион пытается не выдать себя. Задавайте
   вопросы о месте, не называя его. После таймера или досрочного завершения
   ведущим проголосуйте вслух; ведущий выберет подозреваемого и подтвердит выбор.
6. На результате раскрываются место и шпион. Можно сыграть снова с тем же
   составом или выбрать другую игру.

Перезагрузка той же браузерной вкладки сохраняет участие: снова нажмите
«Игры в комнате». Личная карточка после возврата закрыта. Закрытие вкладки,
удаление данных браузера или смена адреса могут потерять доступ; новый вход по
PIN не возвращает прежнюю роль. Фон и обрыв связи скрывают карточку и сохраняют
место. Явный выход отменяет текущую партию; уход ведущего передаёт управление.

Остановка Ctrl+C завершает стенд и удаляет только его временную БД. После
повторного запуска создайте новую комнату. Сборки сохраняются в игнорируемом
`output/play-lan/` или `output/play-internet/`, личные данные туда не записываются.
