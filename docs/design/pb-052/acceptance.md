# PB-052: проверка интерфейса

2026-11-22. Дизайн-система — «Полночный клуб». Настоящая production Flutter
web-сборка, Chromium/Chrome 390×844, отдельные локальные PostgreSQL и API v5.
Браузер работал по HTTPS через временный proxy с отдельным сертификатом,
доверенным только для этой проверки. Публичный сервер не менялся.

- [Каталог с иллюстрациями](catalog.png), [запись входа сцен](catalog-motion.webm).
- [Лобби с читаемой QR-кнопкой](lobby.png).
- [Личный выбор подозреваемого](voting.png).
- [Голос принят, ожидание остальных](voted.png).

В браузере создана тестовая комната, добавлены три синтетических участника,
открыто голосование и реальными нажатиями отправлен личный выбор. Счётчик
стал 1 из 4, раунд остался в voting, форма заменилась личным подтверждением.
QR-кнопка открывает окно приглашения. Для localhost оно правильно объясняет,
почему QR на другом телефоне не сработает; реальный QR и clipboard проверены
widget-тестами с публичным origin. В снимках только синтетические имена и PIN,
токены и закрытые роли не сохранены.

145 Flutter-тестов покрывают в том числе ведущего/участника, обычный и двойной
текст, новый тур и сброс выбора, неизменяемый принятый голос. Анализ чистый.
Движение сцен конечное: лупа, шкала, карточки и предметы завершают вход за
1050 мс; reduced motion показывает финальный кадр. Остальные visual golden
не изменились; golden лобби обновлён после просмотра исправленной кнопки.

Ошибок JavaScript нет; Chrome сообщил предупреждения WebGL ReadPixels при
снятии кадров. Сборка JS прошла; предупреждения wasm dry-run socket_io не
означают проверенную поддержку wasm. Физические Android/iOS, haptics и
профилирование кадров в этой задаче не проверялись.
