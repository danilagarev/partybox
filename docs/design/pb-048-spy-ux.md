# PB-048 — «Шпион» без прокрутки к следующему действию

Пользователь сообщил, что вертикальная прокрутка нарушает поток: для передачи
телефона приходится прокручивать экран вместо того, чтобы только поднять карточку.

## Решение

Основное действие каждого этапа вынесено в постоянную нижнюю область Scaffold:
подготовка, раздача, обсуждение, голосование и повтор. Кнопка учитывает safe area
и находится над клавиатурой. Скрытие роли и прежняя защита повторного нажатия
не зависят от анимации или положения списка.

При обычном размере текста используются компактные заголовки и интервалы,
четыре поля имён размещены в две колонки. Декоративные иллюстрации обсуждения
и результата освобождают место содержимому; большая типографика таймера сохранена.
В раздаче карточка получает высоту по доступному пространству, не меняющуюся
при просмотре. Кнопка передачи всегда присутствует, но до просмотра выключена.
Короткие подписи сохраняют высоту нижней области во время жеста.

Не обрезаются имена, текст роли или основной контент. Для увеличенного шрифта,
12 игроков, длинных имён и служебных сообщений остаётся прокрутка содержимого;
основное действие при этом по-прежнему закреплено. Просмотр через явную кнопку
остаётся доступным для screen reader и чтения крупного текста.

## API общей карточки

`RolePeekCard`: новые необязательные `compact` (false), `surfaceHeight` (null),
`showSafetyHint` (true), `showContinue` (true). Значения по умолчанию сохраняют
прежнее поведение. Ограниченная высота 176–480 logical px предназначена для обычного
текста; caller сохраняет естественную высоту при увеличенном шрифте.
Локальная игра передаёт `showContinue: false`, поскольку передача находится
в закреплённой области. Сетевой caller может использовать тот же API.

## Проверка

`spy_viewport_test.dart`: весь локальный цикл четырёх игроков на 320×640,
360×800 и 390×844 при обычном шрифте, с подключённым хранилищем настроек.
Проверяются нулевая прокрутка и scroll extent на каждом этапе, попадание CTA
и карточки в viewport, неподвижность карточки в жесте, немедленное удаление
секретного дерева после отпускания, повтор партии. Ещё один тест проверяет
доступность CTA над открытой клавиатурой.

Targeted-прогон новых viewport, прежних role_peek и spy_game: 21 тест прошёл.
Прежний крупный шрифт 2 на 320×640 и поведенческие проверки приватности проходят.
Изменённые goldens локальной игры обновляются интегратором после общего ревью.
Физические touch/haptics и TalkBack/VoiceOver требуют отдельной приёмки.
