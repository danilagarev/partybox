# PB-042 — браузерная проверка меню и подключения

2026-11-21, Chrome/Playwright, отдельная сессия `pb042-menu`.
Локальный LAN-стенд, profile Flutter web, viewport 390×844 и 320×640.
Использован skill Playwright; Flutter semantics включена через placeholder.
Публичный адрес, реальный VPS, SSH и GitHub Actions не использовались.

На 390×844 обе карточки и обе кнопки запуска видны сразу без прокрутки.
Различаются марки игр, типы механики и доступные режимы. Правила «Шпиона»
предлагают один телефон и комнату; «Шкала» — комнату на отдельных телефонах.
Общий вход из каталога открывает выбранный режим «Войти по коду», имя и код.

Настройки отклонили по отдельности `https://user:pass@example.com` и
`https://example.com/path`, показав ошибку у поля. Сохранение LAN-origin
вернуло в каталог. HTTP проверялся только в profile LAN-сборке; запрет HTTP
в release подтверждается отдельными unit/widget-проверками интегратора.

Пройден новый сетевой сценарий: карточка «Шкалы» → правила → создание комнаты
ведущим через UI → три синтетических участника через HTTP v3 → лобби с выбранной
«Шкалой терпения» → кнопка начала → первый раунд в фазе ранжирования.
Новая регистрация ведущего произошла один раз. После возврата в каталог выбор
«Шпиона» и вход в комнату восстановили активную «Шкалу»: тот же код, ведущий и
четыре участника. Повторный проход подтвердил буквально неизменный browser access
и отсутствие нового enrollment-запроса; содержимое доступа не выводилось.
После проверки ведущий отменил тестовую партию, комната вернулась в лобби.

На 320×640 каталог прокручивается, вторая карточка, её CTA, вход в комнату и
настройки доступны; горизонтального переполнения нет. Масштаб текста 2× в браузере
отдельно не эмулировался: этот случай покрыт widget-тестами.

После исправления упаковки assets страница загружена с очищенным browser cache.
В итоговом прогоне консоль: **0 errors, 0 warnings**, включая создание комнаты,
v3 joins, начало игры, восстановление и отмену. Ранний прогон выявил отсутствие
FontManifest/ресурсов; после исправления сборки снимки пересняты, Material Icons
и Manrope визуально проверены. Ранние снимки не используются как результат.
