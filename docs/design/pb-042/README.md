# PB-042 — меню двух игр

Дизайн-система: «Полночный клуб», локальный Manrope и существующие токены
`docs/DESIGN_SYSTEM.md`. Продолжаем выбранное направление PB-015.

## Сценарий и иерархия

Каталог отвечает на три вопроса: во что сыграть, сколько нужно людей и телефонов,
как присоединиться к уже играющей компании. Обе игры имеют одинаковый размер
карточек, порядок информации и заметную кнопку. В «Шпионе» можно играть без сети
на одном телефоне или создать комнату. «Шкала терпения» требует личных телефонов;
эта особенность написана в карточке и перед созданием комнаты.

Вместо большой обложки одного «Шпиона» — два компактных игровых блока. В первом
экране 390×844 с обычным масштабом видны названия и кнопки обеих игр. На 360×800
они тоже помещаются (golden `../pb-015/after-catalog.png`). При крупном тексте
карточки растут, каталог прокручивается; текст не ужимается и не обрезается.

Авторская векторная графика: существующий взгляд для «Шпиона» и новый индикатор
предела для «Шкалы». Знаки декоративны, смыслы продублированы словами. Bitmap,
внешние шрифты, платные изображения и новые зависимости не добавлены.

Выбор игры открывает краткие правила и понятный следующий шаг. Для «Шпиона»
есть выбор одного телефона и комнаты; для «Шкалы» — создание комнаты. Игра,
выбранная в каталоге, сохраняется до создания лобби. Для входа по коду выбор
каталога не применяется; активная игра из серверного состояния имеет приоритет.
Гость не переключает игру. Общая кнопка «Войти / вернуться в комнату» ведёт
к вводу кода либо восстановлению сохранённого места без повторной регистрации.
Настройки подключения — отдельное действие после игровых карточек.

Обложки не зависят от наличия адреса сервера в сборке. Настройка комнат вынесена
в отдельный экран, который вызывается при необходимости подключения. Это
устраняет исходную причину исчезновения второй игры из APK: раньше она была
доступна только внутри лобби, а вход в лобби скрывался без ROOM_SERVER_URL.

## Движение и проверка

Вход заголовка использует NightEntrance; маршруты — NightRoute; кнопки — NightButton.
Существующий reduced motion отключает декоративное движение. Циклической анимации,
задержек команд и новых переходов для секретных данных нет.

Widget-проверки: видимость обеих игр без настроенного сервера, 320×640 при тексте
×2 и reduced motion, путь «Шкалы» через resolver до выбранной игры в лобби,
отсутствие переключения игры у гостя, вход по коду и восстановление без enrollment.
Сохранены полный локальный цикл «Шпиона», экран настроек состава и существующий
сетевой цикл «Шкалы». Обновлены только ожидаемо изменившиеся golden каталога
и правил. Golden просмотрен; проверка на физическом телефоне остаётся отдельной.
