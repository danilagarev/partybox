# PB-049 — проверка приглашения

Проверено 2026-11-22 на локальном Flutter Web profile, отдельные контексты Chromium,
LAN origin `http://192.168.1.241:8729`. Это проверка браузера, не камеры телефона.

- [Диалог приглашения](room-invitation.png): QR, код, ссылка и копирование на 390×844.
- Изображение PNG независимо декодировано jsQR 1.4.0: payload содержит только
  origin, корневой путь и `room` из шести цифр; гостевого токена и роли нет.
- [Вход по ссылке](invitation-entry.png): после открытия и перезагрузки PIN
  сохранён; ввод одного имени и «Войти в комнату» привели в реальное лобби.
- Widget-тесты проверяют clipboard/fallback, 320×640 с текстом 2×,
  однократный переход и сохранение прежней комнаты при другом приглашении.
