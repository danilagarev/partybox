# PB-031 — проверка интерфейса

2026-11-21. Используется существующая дизайн-система «Полночный клуб»:
NightPanel, NightButton, типографика Manrope, тёмные поверхности и зелёный акцент.
Новая игра доступна из «Игры в комнате» при сборке с ROOM_SERVER_URL.

## Браузер

Flutter web release, Chrome, 390×844, локальное HTTPS-превью с отдельной PostgreSQL
и настоящим backend. Исключение доверия тестовому сертификату задано только в
проверочном браузере; приложение не меняет проверку TLS. Три других участника —
синтетические HTTP v3 клиенты. Скриншоты просмотрены визуально:

- [Выбор игры и правила](lobby.png).
- [Тайная сортировка героя](ranking.png).
- [Раскрытие и очки](reveal.png).

Проверены создание комнаты через UI, живое обновление состава после трёх входов,
выбор новой игры, начало партии, открытие сортировки, перестановка карточки кнопкой,
подтверждение, раскрытие после трёх закрытых догадок, переход ко второму герою,
открытие/отправка догадки браузерного участника и новый результат с очками.
В закрытой сортировке карточек нет в semantics; после отправки догадки radio-контролы
скрываются. Это два браузерных раунда; полный круг отдельно проверен четырьмя
настоящими Dart HTTP/Socket.IO-клиентами и серверной интеграцией. Дополнительно
полный Dart-цикл обеих игр прошёл в Docker HTTPS smoke с проверкой доверия TLS.

## Автоматические проверки

Widget-тесты проходят сортировку, раскрытие, следующего героя и итог; закрытые
действия при потерянном ответе перечитывают личную проекцию, без записи в vault.
На 320×640 при text scale 2 проверены управление сортировкой, сброс черновика и
скрытие при disconnect/background. Прежние визуальные эталоны «Шпиона» проходят.

Физические Android/iOS, touch, haptics, TalkBack/VoiceOver и profile-замеры не
проверялись. Публичный сервер не развёрнут. Скриншоты содержат только синтетические
данные проверки, не пользовательскую игровую сессию.
